# GMRsVoiage Stream

Sistema leve de overlays e peças visuais para o canal **twitch.tv/rafaelmanu001**, baseado no **GMRsVoiage AquaWave Visual System**.

A proposta é usar HTML/CSS/SVG e JavaScript mínimo para manter as fontes de navegador do OBS leves, editáveis e reutilizáveis.

## Objetivos

- Overlays em HTML/CSS/SVG para OBS Browser Source.
- Visual RetroWave/Synthwave coerente com a identidade GMRsVoiage.
- Pouca dependência de filtros pesados, vídeos em tela cheia ou frameworks.
- Componentes e tokens reutilizáveis.
- Páginas de render para banners e peças estáticas.
- Estrutura fácil de testar e ajustar.

## Estado
